### Aayush Gautam

AI agent and pipeline engineer. I build systems that check their own work before anyone else has to.

I run **Group of AI (GoA)**, a small engineering collective with a simple rule: one member writes the code, a second audits it, and a third verifies every claim against evidence. The structure is the product — every deliverable ships with the test that proves it works and a written note on what it does not do.
